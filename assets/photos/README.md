# Adding your own photos

Drop a `.jpg` file into this folder named after a location's id, and it will
automatically appear on that location's card on the site — no code changes
needed.

Expected file names:

- `rila-monastery.jpg`
- `metoh-orlitsa.jpg`
- `krasta.jpg`
- `rila-village.jpg`
- `tsari-mali-grad.jpg`
- `sapareva-banya.jpg`
- `samokov.jpg`
- `dospey.jpg`
- `tsarska-bistritsa.jpg`
- `seven-lakes.jpg`
- `razdela-saddle.jpg`
- `driska-valley.jpg` (this one's fictional — a moody Rila landscape works well here)

Cards without a matching photo show a "No photo yet" placeholder instead.
